# Nom du projet 
Gestionaire de présence (GDP)
## Présentation 
Une application de gestion de présence en ligne.
## Objectif 
Un outil pour gérer la présences d'individus.
## Fonctionnalités principales
- afficher une liste
- mettre présent / absent un individus
- Crée un rapport de présence
## Technologies envisagées
 - Frontend : HTML et CSS - Backend : PHP - Base de données : Postgre 
## État du projet
- en dévelopement
