Un responsable cherche un moyen de gerer la présence de plusieurs individu. Mon application web qui est un system de gestion de présence pourrait l'aider à gerer les présence de ces individus.



Utilisateur principales : professeurs , employeur/patrons d'entreprise , un infirmier(e)
les droits qu'il onts accées : 
Importer une liste d'une base de donnée; 
Cocher presnet ou absent un individu;
Enregistrer l'etat d'une liste de presence pour faire un rapport de présence;

Mon application permet à des responsables de gerer la présence d'individu afin de les mettres present ou absent.


## Fonctionnalités

L'utilisateur doit pouvoir consulter la liste d'individu.
L'utilisateur doit pouvoir modifier la liste
L'utilisateur doit pouvoir mettre present ou absent les individus.
L'utilisateur doit pouvoir enregistrer l'etat actuel d'une liste pour faire un rapport de présence.
L'utilisateur doit pouvoir consulter l'emploi du temps de l'individu.
L'utilisateur doit pouvoir ajouter / crée des classes et individus
